# NicoLauncher: general news, shown on the launcher's Home page above the
# news of each project. For announcements that are not about one game: a new
# project in the launcher, a change that reaches all of them, a notice.
#
# The launcher reads this file from GitHub (main branch) when it starts and
# on Refresh.
#
# The entry of a release starts with "Launcher X.Y.Z: ": when the user presses
# the launcher's Update, it shows the entries of every version newer than the
# running one, in a window, before updating (and, updated from an older
# launcher that did not, on the first start of the new one). Entries without
# it (a new project, a notice) are only shown on Home.
#
# Format (the same as the projects' news.txt):
#   [N] title      starts entry N (a number one higher than the last; the
#                  title is the date, YYYY-MM-DD, so Home can sort by it)
#   - text         a line of the entry
#   # ...          a comment, never shown
# Newest entry at the top.

[8] 2026-11-15
- Launcher 0.3.8: fixes downloads failing on some PCs with "invalid peer certificate: UnknownIssuer". The launcher now carries its own list of trusted certificates, so it no longer depends on Windows having installed the one GitHub uses
- Portable version: NicoLauncher-portable.zip on the Releases page. Unzip it anywhere and the launcher keeps its settings, build tools and data in that folder, nothing in AppData. It updates itself too. Paths in its config.json can be relative to that folder
- The launcher pauses its animations while you play, so it takes less from your PC behind the game
