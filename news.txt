# NicoLauncher: general news, shown on the launcher's Home page above the
# news of each project. For announcements that are not about one game: a new
# project in the launcher, a change that reaches all of them, a notice.
#
# The launcher reads this file from GitHub (main branch) when it starts and
# on Refresh.
#
# The entry of a release starts with "Launcher X.Y.Z: ": after updating, the
# launcher shows the entries of every version newer than the one the user
# had, in a window on its first start. Entries without it (a new project, a
# notice) are only shown on Home.
#
# Format (the same as the projects' news.txt):
#   [N] title      starts entry N (a number one higher than the last; the
#                  title is the date, YYYY-MM-DD, so Home can sort by it)
#   - text         a line of the entry
#   # ...          a comment, never shown
# Newest entry at the top.
